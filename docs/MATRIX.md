# Дорожная матрица

Без матрицы приложение не рассчитывает автомобильный пробег и прогноз прибытия. Координаты и расстояния по прямой не заменяют дорожные данные. Встроенный сценарий на десять заказов использует явно помеченную синтетическую матрицу.

## GraphHopper Matrix API

1. Получите ключ у официального поставщика [GraphHopper](https://www.graphhopper.com/products/). Проверьте доступ к Matrix API, покрытие нужного района и действующий тариф. Полная матрица из 21 точки содержит 441 направленную пару; стоимость и лимиты определяет поставщик.
2. Введите проверенные широту и долготу даркстора и каждого заказа. Автоматического внешнего геокодирования адресов нет. Порядок полей интерфейса — широта, долгота; запрос GraphHopper преобразует их в `[долгота, широта]`.
3. Введите ключ в настройках и явно нажмите кнопку получения матрицы. Этот запрос передаст GraphHopper координаты всех точек, включая выполненные заказы, необходимые для расчёта от последней доставки. Имена, телефоны, адреса, номера квартир и идентификаторы заказов не передаются. Сам факт набора координат также чувствителен: запрашивайте внешний сервис только при допустимости такой передачи.
4. Ключ хранится только в оперативной памяти текущего процесса, не сохраняется в Room и не выводится в журнал. Повторное получение матрицы может расходовать квоту. Приложение не опрашивает API автоматически после каждой доставки.

Адаптер обращается по HTTPS к официальному синхронному endpoint `https://graphhopper.com/api/1/matrix`, использует автомобильный профиль `car`, массивы `times` и `distances`, `fail_fast=true`. Формат запроса сверяется с [официальным клиентом GraphHopper](https://github.com/graphhopper/graphhopper/blob/master/client-hc/src/main/java/com/graphhopper/api/GHMatrixAbstractRequester.java) и [справочником API](https://docs.graphhopper.com/openapi/matrices/postmatrix). Неполные ответы, недоступные пары точек и ошибки API отклоняются. Старые данные не заменяются вымышленными оценками.

Матрица содержит дорожные расстояния и базовое время движения. **Этот адаптер не получает текущие пробки.** Даже свежая матрица не гарантирует точного прибытия: прогноз зависит от парковки, обслуживания, дорожной ситуации и исходной позиции. Времена округляются вверх до целых секунд. Статическая матрица не моделирует зависимость времени движения от момента выезда. Для другого официального поставщика добавьте адаптер с тем же результатом `TravelMatrix`; учитывайте его лицензию, покрытие, условия передачи координат и стоимость.

## Импорт JSON без запроса из приложения

Подготовьте полную направленную матрицу из разрешённого дорожного сервиса и выберите её через системный выбор файла. JSON не должен содержать клиентские имена, телефоны, коды доступа, квартиры или скриншоты. Максимальный размер — 2 МБ; максимум 21 точка: даркстор и 20 заказов.

```json
{
  "version": 1,
  "nodeIds": ["depot", "TEST-01", "TEST-02"],
  "seconds": [[0, 600, 900], [540, 0, 300], [840, 420, 0]],
  "meters": [[0, 2500, 3600], [2300, 0, 1200], [3400, 1600, 0]],
  "capturedAt": 1793030400,
  "source": "Синтетический пример формата, не дорожные данные",
  "isDemo": true
}
```

Это пример формата с искусственными числами. Не используйте его как реальный маршрут. Для рабочих данных укажите реальный источник, время его получения и `isDemo: false`.

- `nodeIds`: уникальные идентификаторы в порядке строк и столбцов. `depot` — зарезервированное имя даркстора. Другие значения должны точно совпадать с проверенными ID заказов. Два заказа по одному адресу остаются двумя разными ID и двумя точками в матрице; между ними допустимо нулевое движение, если это подтверждено исходными данными.
- `seconds`: время движения в секундах для каждой направленной пары. Парковка, подъезд, лифт и передача заказа задаются отдельно как обслуживание.
- `meters`: дорожное расстояние в метрах для каждой направленной пары. Матрица может быть асимметричной из-за односторонних улиц.
- `capturedAt`: абсолютное время получения дорожных данных, Unix timestamp в секундах, не миллисекундах.
- `source`: короткое название дорожного источника и ограничения прогноза.
- `isDemo`: обязательный логический признак искусственных данных.

Все значения должны быть числовыми, конечными и неотрицательными. Диагонали — нулевые. `null`, пропущенные пары, строки вместо чисел и неподдерживаемые значения отклоняются. После изменения состава точек, координат или даркстора получите новую матрицу. После доставки существующая матрица позволяет пересчитать остаток от ID выполненного заказа; старение дорожных данных нужно учитывать отдельно.
