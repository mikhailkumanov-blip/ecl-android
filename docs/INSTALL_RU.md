# Установка VV Курьер PRO на POCO F7 без компьютера

APK будет доступен после **фактически успешной** сборки GitHub Actions. Красный, отменённый или ещё работающий запуск не означает, что приложение готово. Проверка на физическом POCO F7 пока не выполнена.

## Скачать APK в браузере телефона

1. Войдите в свой GitHub-аккаунт в Chrome или другом браузере телефона.
2. Откройте [репозиторий](https://github.com/mikhailkumanov-blip/ecl-android), затем вкладку **Actions** → **Android APK**. Прямая ссылка: [список сборок](https://github.com/mikhailkumanov-blip/ecl-android/actions/workflows/android.yml).
3. Выберите последний запуск для ветки `main` с **зелёной галочкой**. Дождитесь завершения шага `Test, assemble and lint` и загрузки `APK`.
4. Прокрутите страницу запуска до **Artifacts** и нажмите **VV-Courier-PRO-debug**. Браузер скачает ZIP-архив. Если раздел не виден, включите «Версия для ПК» в меню браузера. Для скачивания artifact обычно требуется вход в GitHub.
5. В приложении «Файлы» или файловом менеджере POCO откройте «Загрузки», найдите ZIP и выберите «Извлечь». Внутри находится `app-debug.apk`.

Artifact хранится 30 дней. Если срок хранения истёк, во вкладке Actions откройте workflow **Android APK**, нажмите **Run workflow**, выберите `main` и дождитесь успешной сборки. Для этой кнопки нужны права на репозиторий.

## Установить

1. Нажмите на извлечённый `app-debug.apk`.
2. Если HyperOS блокирует установку, откройте предложенные системой настройки и временно разрешите **«Установка неизвестных приложений»** для того файлового менеджера или браузера, которым открыли APK. Название раздела зависит от версии HyperOS; можно найти его поиском в «Настройках».
3. Вернитесь к APK и нажмите «Установить». Не отключайте Play Защиту или другие системные проверки. Устанавливайте файл только из своего репозитория и успешного запуска.
4. После установки отзовите выданное файловому менеджеру/браузеру разрешение на установку неизвестных приложений.
5. Откройте **VV Курьер PRO**. Для проверки выберите «Настройки» → «Загрузить демо · 10 заказов». Демо не содержит реальных клиентов и использует синтетические времена и расстояния.

Приложение не требует доступа ко всем фото, SMS, контактам или специальным возможностям. Выбирайте нужные изображения в стандартном Photo Picker либо отправляйте их через «Поделиться» → «VV Курьер PRO». Если приложение не появилось в меню сразу, откройте его один раз и повторите.

## Обновления и устранение проблем

- Это debug APK. Автоматической публикации в Google Play и автоматических обновлений нет.
- На независимых запусках GitHub Actions стандартный debug-ключ подписи может меняться. Если Android сообщает, что подпись не совпадает, старую версию придётся удалить перед установкой новой. **Удаление стирает локальные заказы и историю текущей смены.** Завершите смену и сохраните нужные итоговые суммы отдельно заранее. Стабильная release-подпись — следующий этап разработки.
- Сообщение «Ошибка синтаксического анализа» или «Пакет повреждён»: проверьте, что открыт APK после извлечения ZIP, а скачивание завершилось. Повторно скачайте artifact из зелёной сборки.
- APK не найден: проверьте результат workflow. При ошибке сборки откройте красный шаг и журнал; готовность приложения в этом случае не подтверждена.
- OCR не распознал карточки: проверьте резкость и масштаб скриншота, время его получения; исправьте карточки вручную. Не публикуйте реальные скриншоты в issue или комментарии GitHub.
- Нет прогноза прибытия: нужны подтверждённые заказы и дорожная матрица. Приложение намеренно не вычисляет рабочие километры по прямой.
- Яндекс Навигатор не открывается: установите его отдельно из доверенного магазина. Адрес передаётся приложению навигации только по нажатию пользователя.

Для голосовых уведомлений в системе должен быть доступен русский синтезатор речи. MVP предупреждает при пересчёте и не является фоновым навигационным сервисом. Проверяйте маршрут и изменяйте данные во время безопасной остановки.
